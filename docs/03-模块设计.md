# md2style 模块设计与接口契约

## 模块划分
| 模块 | 层级 | 物理路径 | 核心职责 |
|------|------|---------|---------|
| CLI | 接口 | `md2style/cli.py` | 子命令解析、参数装配 |
| Web Interface | 接口 | `md2style/interfaces/web/` | 本地 Web 服务、表单采集、结果展示（纯 Python，普通用户入口） |
| Orchestrator | 编排 | `md2style/orchestrator.py` | 路由、白名单校验、流程 |
| Style Engine | 规则 | `md2style/engines/style_engine.py` | 样式合并与校验 |
| MD Parser | 规则 | `md2style/engines/md_parser.py` | MD → IR |
| Learner | 规则 | `md2style/engines/learner.py` | docx → YAML |
| Renderers | 接口(执行) | `md2style/renderers/` | IR → 目标格式 |
| Core | 规范 | `md2style/core/` | IR/常量/错误码 |
| Utils | 规范/存储 | `md2style/utils/` | 颜色/字体/日志 |

## 预定义样式资产清单（数据存储层）
| 格式 | 预设文件名 | 风格定位 | 关键样式特征 |
|------|-----------|---------|-------------|
| docx | `styles/paper.yaml` | 论文风格 | 章节编号、宋体/Times、1.5 倍行距、图表题注 |
| docx | `styles/official.yaml` | 公文风格 | 仿宋/红头、标题居中、特定页边距、文号格式 |
| html | `styles/claude.yaml` | Claude (Anthropic) 风格 | 克制留白、衬线标题、柔和分割线、中性色 |
| html | `styles/mac.yaml` | Mac 风格 | 圆角卡片、SF 字体栈、毛玻璃质感、系统配色 |
| ppt  | `styles/claude.yaml`（复用） | 同 html claude | 母版主题色/字体对齐 html |
| ppt  | `styles/mac.yaml`（复用） | 同 html mac | 母版主题色/字体对齐 html |

> 用户通过 Web "学习"功能生成的样式写入 `styles/<自定义名>.yaml`，与内置预设同目录、同等可选。

## 接口契约

### CLI（`md2style/cli.py`）
```python
def main(argv: list[str] | None = None) -> int: ...
# 子命令签名（稳定，受不变量 I 保护）：
#   convert  -i <input.md> -o <output.{docx,html,pptx}> -s <style> [--h1-size N] [--h1-color #xxx] [--body-font NAME] [--line-height F]
#   learn    -t <template.docx> -n <style_name>
#   preview  -i <input.md> -s <style>
```

### Orchestrator（`md2style/orchestrator.py`）
```python
def run(args: argparse.Namespace) -> int: ...
def dispatch_subcommand(args: argparse.Namespace) -> int: ...
# 白名单：仅接受上述 CLI 声明参数；未知参数 → 抛 ParamWhitelistError 并退出
```

### Style Engine（`md2style/engines/style_engine.py`）
```python
def resolve(style_name: str, cli_overrides: dict) -> dict: ...
# 返回 final_style（DEFAULT < YAML < CLI 合并后）
def validate(style_dict: dict) -> None: ...
# 校验颜色 #RGB、字号 8~72pt、字体存在；失败抛 StyleValidationError
```

### MD Parser（`md2style/engines/md_parser.py`）
```python
def to_ir(md_text: str) -> list[IRNode]: ...
# IRNode: {type: heading|paragraph|list|code|table, level?, text?, lang?, align?, meta?}
```

### Learner（`md2style/engines/learner.py`）
```python
def learn(docx_path: str, name: str) -> str: ...
# 精准模式：读 Heading1/Heading2/Normal 标准样式
def learn_heuristic(docx_path: str) -> dict: ...
# 启发式：按字号/加粗聚类 → H1/H2/body；返回 StyleConfig 同构 dict
# 输出：styles/<name>.yaml（含 "# 自动学习自: xxx.docx"）
```

### Renderers（`md2style/renderers/base.py`）
```python
from abc import ABC, abstractmethod
class RendererBase(ABC):
    @abstractmethod
    def render(self, ir: list[IRNode], final_style: dict, output_path: str) -> None: ...
# 子类：DocxRenderer / HtmlRenderer / PptRenderer
# 分发：RendererDispatcher.by_suffix(output_path) -> RendererBase
```

### Core（`md2style/core/`）
```python
# ir.py: IRNode / IR 类型定义
# constants.py: DEFAULT_STYLE 兜底、字号/颜色边界常量、错误码
# errors.py: StyleValidationError, ParamWhitelistError
```

### Web Interface（`md2style/interfaces/web/`）
```python
# 纯 Python 本地 Web 服务（PyWebIO / Streamlit 类方案），不打包二进制
def start(host: str = "127.0.0.1", port: int = 8080) -> None: ...
# 表单字段与 CLI 参数一一对应：input 上传 / style 下拉 / h1-color 色板 / h1-size 滑块
def handle_convert(form: dict) -> str: ...   # 返回输出文件下载链接
def handle_learn(form: dict) -> str: ...     # 返回生成 yaml 名 + 提示
def handle_preview(form: dict) -> str: ...   # 返回临时 html 预览链接
# 内部：form -> argparse.Namespace 等价 dict -> Orchestrator.run，界面层不含业务规则
```

### Utils（`md2style/utils/`）
```python
# color.py: hex_to_rgb(hex) -> (r,g,b); is_valid_hex(s) -> bool
# fonts.py: font_exists(name) -> bool
# logger.py: get_logger(name) -> Logger
```
